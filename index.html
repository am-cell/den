Violet Light MIMO VLC Systems

Researching the feasibility of violet light replacing blue light in MIMO Visible Light Communication systems — blue light has significantly greater effects on sleep, arrhythmia, and mental health. Compared violet vs. blue across communication performance and biological safety criteria.

VLCMIMOPhotonicsResearch

Tremor Analysis Wearable

Biomedical signal processing research for wearable tech, analyzing tremors in patients using real-time signal processing. Submitted to the James Dyson Award and selected for Monash UROP research.

Signal ProcessingWearablesSTM32UROP

FPGA Camera + Haptic Feedback System

FPGA system with camera interfacing, user inputs, and ADXL345-based haptic feedback. Built parallel processing on the FPGA to handle multiple input streams simultaneously, with SPI interfacing for the camera and VGA output.

FPGASPIVGAADXL345Parallel Processing

16-bit RISC CPU in Verilog

Real-Time Audio Processing on STM32

Implemented real-time audio sampling and filtering at 44.1 kHz using UART + DMA on STM32 microcontrollers, streaming processed audio to a PC.

Analog True RMS Converter

Designed and built a discrete analog true RMS-to-DC converter using op-amps and passive components. Analysed RMS accuracy for non-sinusoidal waveforms through LTSpice simulation and experimental validation.
